# Developer Prompt Used

Create a simple legacy retail operations web application with React frontend, FastAPI backend, PostgreSQL database, Redis queue, and Python worker.

It should include:
- product management
- inventory tracking
- customer management
- order management
- billing-style order records
- dashboard page
- health endpoint
- readiness endpoint
- metrics endpoint
- environment variables
- minimal tests

Keep code simple and DevOps-friendly. The DevOps engineer will handle Docker, Kubernetes, Helm, Terraform, Ansible, CI/CD, GitOps, monitoring, logging, backup, restore, and incident recovery.
